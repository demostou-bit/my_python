## 🚀 `split_all.py` の使い方

1. `split_all.py` と同じディレクトリに `input` と `output` フォルダを配置する。
2. 左右に分割したい PNG ファイルを `input` フォルダに移動する。
3. 以下のコマンドを実行する：
   ```bash
   python split_all.py
